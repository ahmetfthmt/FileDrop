# File Drop

Telefon, tablet ve bilgisayar arasında QR kodu veya kısa oda kodu ile dosya aktarımı yapan, mobil öncelikli bir web uygulaması ve Android debug uygulaması.

File Drop; hesap açmadan, kalıcı dosya depolamadan ve dosyaları varsayılan olarak bir üçüncü taraf servise yüklemeden çalışmak üzere tasarlanmıştır. Uygun ağlarda dosyalar WebRTC DataChannel üzerinden doğrudan iki cihaz arasında aktarılır. Doğrudan WebRTC bağlantısı kurulamazsa, uygulama uçtan uca şifrelenmiş geçici relay aktarımına geri döner.

> **Durum:** Mevcut sürümün TypeScript kontrolü, üretim derlemesi ve 10 otomatik testi başarılıdır. Android debug APK çıktısı da oluşturulmuş ve APK arşiv bütünlüğü doğrulanmıştır.

## Nasıl çalışır?

### 1. Oda oluşturma

Oda sahibi cihazı `/api/signal` WebSocket uç noktasına bağlanır ve `create` mesajı gönderir. Sunucu rastgele bir oda kodu ve uzun bir oturum token’ı oluşturur. Token sunucuda yalnızca SHA-256 özeti olarak tutulur.

Oda bilgisi QR koduna ve paylaşılabilir bağlantıya dönüştürülür. Oda varsayılan olarak 10 dakika aktiftir; aktivite olduğunda süresi yenilenir.

### 2. Odaya katılma

İkinci cihaz QR kodunu okur veya oda kodunu elle girer. QR bağlantısında oturum token’ı varsa eşleşme doğrudan yapılabilir. Sadece oda kodu kullanılıyorsa, ikinci cihazın isteği oda sahibine `pair-request` olarak iletilir ve oda sahibi eşleşmeyi onaylar.

### 3. WebRTC bağlantısı

Eşleşme sonrasında cihazlar WebRTC teklif, cevap ve ICE adaylarını WebSocket sinyalleşme sunucusu üzerinden değiştirir. Dosya içeriği sinyalleşme sunucusundan geçmez; uygun ağlarda dosya WebRTC DataChannel üzerinden cihazlar arasında gider.

### 4. Şifreli relay geri dönüşü

Bazı NAT, güvenlik duvarı veya operatör ağlarında doğrudan WebRTC bağlantısı kurulamayabilir. Bu durumda host cihazı rastgele bir AES-GCM anahtarı üretir ve anahtarı WebRTC sinyalleşme kanalında karşı cihaza iletir. Relay paketleri sunucu üzerinden geçse bile içerikleri AES-GCM ile şifrelenir.

Relay modu dosyanın sunucuda kalıcı olarak saklandığı anlamına gelmez. Sunucu yalnızca şifreli geçici paketleri iki WebSocket bağlantısı arasında iletir.

## Kurulum

```bash
git clone <depo-adresi>
cd file-drop
pnpm install
```

Geliştirme sunucusunu başlatmak için:

```bash
pnpm dev
```

Üretim build’i için:

```bash
pnpm run build
NODE_ENV=production pnpm start
```

İstemci, sinyalleşme adresini şu kuralla belirler:

1. `VITE_REMOTE_ORIGIN` varsa onu kullanır.
2. Yoksa mevcut sayfanın origin’ini kullanır.
3. `https:` adresini `wss:` adresine, `http:` adresini `ws:` adresine çevirir.
4. WebSocket yolu her zaman `/api/signal` olur.

Örnek:

```bash
VITE_REMOTE_ORIGIN=https://example.com pnpm run build
```

Bu durumda sinyalleşme adresi:

```text
wss://example.com/api/signal
```

## Android debug APK

Android kaynakları Capacitor ile senkronize etmek ve debug APK üretmek için:

```bash
export VITE_REMOTE_ORIGIN=https://example.com
pnpm run android:debug
```

APK şu konumda oluşur:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

`VITE_REMOTE_ORIGIN` verilmeden Android debug build’i çalıştırılmaz. Bu, APK’nın yanlışlıkla yalnızca yerel bilgisayar adresine bağlanmasını önlemek içindir.

## Ağ ve bağlantı sınırları

- Oda eşleştirmesi için çalışan bir HTTPS/WebSocket sunucusu gerekir.
- HTTPS yayınında WebSocket bağlantısı WSS olmalıdır. HTTP sayfadan HTTPS/WSS uç noktasına geçiş tarayıcılar tarafından engellenebilir.
- Android tarafında standart WebView WebSocket yerine native OkHttp WebSocket kullanılır.
- WebRTC bağlantısı her ağda garanti edilemez. STUN kullanılır; TURN sunucusu bu sürümde zorunlu değildir.
- Relay geri dönüşü uygulama sunucusunun WebSocket bağlantılarını açık tutmasını gerektirir.
- Sunucu yeniden başlatılırsa aktif odalar ve eşleşmeler kaybolur.
- Oda varsayılan olarak 10 dakika sonra kapanır.
- Sunucu belleğinde aktif oda sayısı 10.000 ile sınırlıdır.
- Aynı IP adresinden dakikada en fazla 12 katılım/oda oluşturma denemesi kabul edilir.
- Relay paketleri 100.000 karakter ile sınırlıdır; büyük dosyalar küçük parçalara bölünür.
- Alınan dosyalar tarayıcı belleğinde geçici Object URL olarak tutulur. Sayfa kapatılırsa indirilmemiş dosyalar kaybolabilir.
- Mobil tarayıcılarda arka plana geçme, ekran kilidi, işletim sistemi pil tasarrufu ve ağ değişimi bağlantıyı duraklatabilir.

## Güvenlik notları

- Dosya içeriği varsayılan WebRTC modunda sinyalleşme sunucusundan geçmez.
- Relay modunda sunucu yalnızca AES-GCM ile şifrelenmiş paketleri görür.
- Oda token’ı istemciye yalnızca oda oluşturma yanıtında verilir ve QR bağlantısında taşınabilir. QR bağlantısını yalnızca güvendiğiniz kişilerle paylaşın.
- Oda kodu tek başına uzun süreli bir kimlik doğrulama mekanizması değildir; oda sahibinin eşleştirme onayını kullanın.
- Bu proje kötü niyetli dosya içeriği taraması, antivirüs taraması veya kullanıcılar arası güven politikası sağlamaz.
- Üretimde mutlaka HTTPS, güvenilir reverse proxy, log temizleme ve uygun rate limit politikası kullanın.

## API ve harici servis bağımlılıkları

File Drop’un dosya transferi için herhangi bir AI API’si, ücretli dosya depolama API’si veya üçüncü taraf dosya aktarım servisi gerekmez. Oda oluşturma ve WebRTC sinyalleşmesi, bu projenin kendi Express/WebSocket sunucusu tarafından yapılır.

Bu depo başlangıçta bir web uygulaması şablonundan türetildiği için bazı şablon dosyaları hâlâ bulunabilir:

- Manus OAuth iskeleti
- Forge/LLM/görüntü/ses entegrasyonu yardımcıları
- Örnek harita ve bildirim yardımcıları
- Şablon kullanıcı/veritabanı altyapısı

Bunlar File Drop’un temel transfer akışının gereksinimi değildir. GitHub’a sade ve sağlayıcıdan bağımsız bir sürüm gönderilecekse bu kullanılmayan şablon parçaları ayrıca kaldırılmalı; `package.json`, `template.json`, auth rotaları, ilgili env değişkenleri ve kullanılmayan UI bileşenleri birlikte temizlenmelidir. README, bu parçaların mevcut sürümde tamamen silindiğini iddia etmez.

Kendi API veya depolama sağlayıcısını eklemek isteyenler bunu transfer çekirdeğinden bağımsız bir entegrasyon olarak uygulamalıdır. Dosya transferinin temel sözleşmesi `server/signaling.ts`, `client/src/hooks/useTransfer.ts` ve `shared/transfer.ts` dosyalarındadır.

## Sorun giderme

### “Bağlantı sunucusuna ulaşılamadı”

- Yayın adresinin HTTPS olduğundan emin olun.
- Android build sırasında `VITE_REMOTE_ORIGIN` değerinin doğru olduğundan emin olun.
- `https://alan-adı/api/signal` için reverse proxy’nin WebSocket upgrade başlıklarını geçirdiğini kontrol edin.
- Android cihazın internete erişebildiğini kontrol edin.
- Eski APK’yı kaldırıp yeni debug APK’yı kurun; Capacitor web asset’leri APK içine build sırasında gömülür.

### “Oda oluştur” düğmesi bekliyor

- WebSocket’in `wss://alan-adı/api/signal` adresine bağlanıp bağlanmadığını kontrol edin.
- Sunucu loglarında upgrade veya TLS hatası olup olmadığını kontrol edin.
- APK’nın uzak sunucu adresiyle build edildiğini doğrulayın.
- Aynı cihazda tarayıcı sürümünü açıp oda oluşturmayı deneyin. Tarayıcı çalışıyor, APK çalışmıyorsa native WebSocket veya APK’nın eski origin ayarı incelenmelidir.

### QR kamera açılmıyor

- Android kamera iznini verin.
- Tarayıcıda kamera erişimi için HTTPS kullanın.
- QR yerine 6 karakterli oda kodunu elle girin.
